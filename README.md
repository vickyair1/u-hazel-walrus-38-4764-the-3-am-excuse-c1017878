One line, under 200 characters: the excuse a hardware wallet gives for refusing to sign a transaction at 3 AM.

See the bounty: https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878

## How it works

`main.py` writes a single line to `/output/entry.txt`. The line is the wallet speaking for itself: its signing keys keep office hours, and at 3 AM both the keys and the owner's judgment are off the clock — so it refuses until sunrise.

Run it:

```sh
python3 main.py
```
